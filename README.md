# 清单日历（dida-clone）

模仿滴答清单网页版「日历」页面的日程管理应用。基于 **Vue 3 + Vite + Express + SQLite**，对照保存的原版页面逐一复刻了全部功能，样式提取自原站 blacksea-photograph-pro-theme（主色 #484553、灰阶 rgba(25,25,25,x)、背景照片、48 个原版 SVG 图标）。

## 一、原网页功能清单 → 复刻情况

### 1. 左侧图标栏（50px 深色栏）
| 功能 | 说明 | 状态 |
| --- | --- | --- |
| 用户头像 | 点击打开设置（主题色自定义） | ✅ |
| 任务 | 清单列表视图：按清单筛选、显示已完成、过期红字 | ✅ |
| 日历 | 本应用核心（月/周视图） | ✅ |
| 四象限 | 艾森豪威尔矩阵（重要×紧急），任务可跨象限拖拽 | ✅ |
| 专注 | 番茄钟 25/5 分钟、环形进度、关联任务 | ✅ |
| 倒数日 | 纪念日/倒数日/生日/节日卡片 | ✅ |
| 习惯 | 备份数据中无对应模块 | ⏳ 占位页 |
| 搜索 | Ctrl+K 全局搜索标题/备注/标签 | ✅ |
| 同步 / 通知 / 帮助 | 本地即时同步；通知/帮助为提示 | ✅ |

### 2. 迷你月历（日历左上面板）
- 年月标题 + 上/下月切换 + 「今天」圆点按钮
- 点击标题展开 年份列表 + 12 个月网格选择器
- 周一起始表头、周末置灰；每日农历/节日（初一显示月名）
- 法定节假日小图标（元旦/劳动节/国庆/春节/端午/中秋）
- 有任务的日期底部小圆点；今天描边、选中日主色圆底

### 3. 筛选面板（日历左下面板）
- 「所有」总开关（圆形复选框）
- 清单分组（可折叠）：收集箱 + 各清单（emoji + 勾选，多选）
- 标签分组（可折叠）：单选筛选
- 订阅日历分组（入口占位）

### 4. 日历顶部导航
- 筛选按钮；当前月份大标题（20px 半粗，点击弹出月份选择器）
- 「+」快速添加；视图切换下拉（月/周）
- 前进 / 今天 / 后退按钮组
- 更多菜单：隐藏(显示)已完成任务 / 导入滴答 CSV 备份 / 打印日历

### 5. 月视图
- 周一~周日表头，周末列浅灰底；6 行 × 7 列
- 日期数字 + 农历/节气/节日（节日绿色）+ 每周第 N 周
- 今天数字主色圆底；每月 1 日显示「N月1日」
- 任务色块：清单色 56% 透明度背景（完成后 18% + 删除线置灰，与原版内联样式一致）
- 定时任务右侧显示时间；跨天任务逐日显示
- 格子容量自适应，「还有 N 个任务…」浮层查看全部
- 双击空白格快速添加当天任务；拖拽任务到其他日期改期（保留时长）
- **点击任务 → 详情就地弹出**（弹层定位在点击位置旁，380px 适中尺寸，点外部关闭）

### 6. 周视图
- 7 列日期头（今天高亮）+ 全天任务区 + 24 小时时间网格（56px/小时）
- 定时任务按起止时间定位色块；当前时间红线
- 双击小时槽快速添加定时任务；全天/定时区均可拖拽改期

### 7. 快速添加任务弹窗
- 「准备做什么？」大号输入；Enter 提交
- 日期（今天/明天/下周快捷 + 日期时间 + 全天开关）
- 优先级（无/低/中/高，旗帜图标）；清单（emoji 下拉）
- 标签（历史点选 + 新建）；更多（备注）

### 8. 任务详情（就地弹层）
- 完成/撤销勾选（优先级色）；标题行内编辑
- 日期 + 时间 + 全天；重复（每天/每周/每月/每年）
- 优先级、清单、标签增删、备注、子任务增删改
- 创建/完成时间戳；删除（级联子任务）

### 9. 四象限（艾森豪威尔矩阵）
- 与原版一致的四象限布局：重要且紧急 #FF5F68 / 重要不紧急 #FFB000 / 不重要但紧急 #4772FA / 不重要不紧急 #0CCE9C
- 象限内按日期分组：今天 / 最近7天 / 更远 / 无日期
- **任务可在四个象限间自由拖动**：拖入后自动更新优先级（重要=高）与截止日期（紧急=今天）
- 40px 任务行（勾选框/标题/清单/日期提示），双击空白快速添加

### 10. 倒数纪念日
- 卡片网格（照片背景 + 大数字，与原版 277×173 卡片一致）
- 类型分类筛选：所有 / 纪念日 / 倒数日 / 生日 / 节日
- 纪念日：显示「已经 X年Y月Z天」；倒数日：剩余天数
- 支持农历（春节/中秋等，除夕自动适配 29/30 天月）、每年重复
- 添加/编辑/删除/置顶；预置 8 个节日（元旦/除夕/春节/元宵/端午/中秋/国庆/圣诞）

### 11. 专注（番茄钟）
- 25/5 分钟、环形进度、关联今日任务

### 12. 设置（点击头像）
- 主题颜色自定义：8 个预设色板 + 自定义取色器
- 即时生效（CSS 变量）并 localStorage 持久化，可恢复默认

### 13. 数据与搜索
- SQLite 存储（tasks / projects / folders / countdowns，软删除，WAL）
- REST API（bootstrap / tasks CRUD / projects CRUD / countdowns CRUD / search / import）
- 滴答清单 CSV 备份导入：清单(emoji)、文件夹、标签、起止时间(时区换算)、全天、优先级(0/1/3/5)、状态(0/-1/2)、子任务(parentId)
- 全局搜索（Ctrl+K）：标题/备注/标签 LIKE 匹配

## 二、技术栈

| 层 | 技术 |
| --- | --- |
| 前端 | Vue 3.5 `<script setup>`、Vite 6 |
| 后端 | Express 4 + Node 24 内置 `node:sqlite`（零原生依赖） |
| 农历/节日 | lunar-javascript（农历/节气/传统节日）+ 内置法定节假日 |
| 图标 | 从原站 SVG 雪碧图提取的 48 个 symbol，`<use>` 引用 |
| 主题 | 原站 blacksea 摄影主题设计变量 + 背景照片 |

## 三、快速开始

```bash
# 1. 安装依赖（前后端）
npm run install:all

# 2. 导入滴答清单 CSV 备份（可选；不导入则为空库）
npm run import -- "C:/Users/yeeiee/Downloads/新建文件夹/Dida-backup-2026-09-02.csv"

# 3. 启动后端 http://localhost:4300
npm run server

# 4. 启动前端开发服务器 http://localhost:5180
npm run client
```

也可以在页面内导入：日历右上「更多 ⋮」→「导入滴答清单 CSV 备份…」输入路径。

### 测试环境（数据隔离，见 AGENTS.md）

所有测试必须使用独立测试库，不得触碰正式库 `data/schedule.db`：

```bash
# 测试服务器（端口 4301）
DIDA_DB_PATH=data/schedule.test.db PORT=4301 node server/index.js

# 测试数据导入
DIDA_DB_PATH=data/schedule.test.db node server/import-csv.js <csv路径>
```

### 生产模式

```bash
cd client && npm run build     # 产出 client/dist
cd ../server && npm start      # 直接访问 http://localhost:4300
```

## 四、数据说明

- 数据库文件 `data/schedule.db`；导入会清空并重建 projects/tasks/folders
- 任务字段与滴答 CSV 对应：标题/备注/清单/标签/起止时间/全天/优先级/状态/重复/排序/子任务
- 说明：原备份 CSV 导出时间早于保存的网页快照，网页中个别最新任务不在 CSV 中属正常现象
